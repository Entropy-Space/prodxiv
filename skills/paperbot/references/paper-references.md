# Paper references

Use this component for Background, Related Work, inline citations, and the
References section.

1. Identify specific related products, websites, repositories,
   documentation, standards, or papers.
2. Prefer official sites, documentation, and source repositories for claims
   about a product's behavior.
3. Use independent sources when a comparison requires an outside perspective.
4. Explain whether each work is an influence, dependency, alternative, or
   predecessor instead of listing names.
5. Place a descriptive Markdown link near each externally verifiable claim.
6. Include complete, publicly inspectable links in References.
7. Mark unsupported comparisons for author review.

Never disclose private repository text, paths, or implementation details in a
search query or public citation.
